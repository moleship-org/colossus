# Agents

## About

The name of this project is "colossus". A web-based graphical interface for managing Podman containers using "moleship" as the backend.

Moleship is a RESTful API backend service that provides a way to manage quadlet unit files. It allows you to interact with the underlying systemd instance of the backend and manage your containers remotely.

## Core Dependencies

* nuxtjs v4
* pnpm
* tailwindcss
* typescript

## How to build

Just run `pnpm build`.
